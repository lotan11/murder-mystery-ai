# MakeHuman core source assets

SPDX-License-Identifier: CC0-1.0

Unmodified selected core files from the official system asset pack. Individual mesh, fitting and material headers explicitly state release as CC0 in September2020 and retain original copyright/source information. Exact URL, archive ETag, per-file byte counts and SHA256 are in SOURCE.json. Retrieval used selected HTTP ZIP ranges with ZIP CRC checks; no full-archive hash is claimed.

Only short02 hair and the authored old_caucasian_male diffuse/material are included. No community asset with conflicting headers is redistributed here. Derived silver hair and blended skin images are separate project-generated material outputs. These are development materials, not approved portrait likeness or a de-lit/photogrammetric skin scan.
