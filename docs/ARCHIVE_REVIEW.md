# Repository and source inspection

Inspected and cloned `https://github.com/lotan11/murder-mystery-ai.git` before implementation. The remote had no branches, commits, application files, or repository instructions. This commit establishes the initial application on `main`.

Reused the tested local Wobblebottom vertical slice developed earlier in this conversation rather than rebuilding an unrelated scaffold. It supplies the React host/guest/TV views, procedural Three.js avatar, deterministic FastAPI case, and WebSocket transport. This repository adds Windows startup automation, self-starting end-to-end tests, current pinned FastAPI/Uvicorn versions, and CI.

The earlier supplied `mystery-prototype.zip` was also inspected before that work. It contained a small FastAPI server, single HTML page, requirements and README, with no React, assets, tests or canonical mystery. Its useful concepts were room fan-out, reconnect snapshots, pause/resume and scripted dialogue. Its unauthenticated organizer actions and emoji avatar were replaced.
