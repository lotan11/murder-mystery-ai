# Casting concept image prompts

Generated October 28, 2026 with the built-in `image_gen` tool, one independent generation per candidate, opaque background. No reference images or paid API calls were used. The original generated PNGs were copied into `frontend/public/casting/`; they are conceptual visual candidates, not 3D meshes or animation rigs.

## Shared prompt (prepended to each candidate)

Create one premium stylized-realistic 3D character concept portrait for an original fictional British detective named Reginald P. Wobblebottom, for an elegant murder mystery dinner game. AAA narrative game art direction, believable mature human facial anatomy, realistic understated lips with mouth CLOSED, skin and cloth with tasteful stylization but no caricature, grounded cinematic realism, refined charisma and very subtle knowing warmth in the eyes, no exaggerated eyebrow, no grin, no slapstick or cartoon proportions. Waist-up portrait facing almost forward, looking toward viewer, centered, head fully visible with generous margins. Warm soft key light with natural skin values, understated teal rim light, softly blurred dark manor library background, sophisticated charcoal/forest green palette. Image contains ONE character only, no text, no labels, no collage, no watermark. This is concept art for later 3D rigging, not a photo of a real person.
